QUICK START (6 STEPS)
================================================================================

STEP 1: Download all files to your R project directory

STEP 2: Set your OneDrive path
  Open 00_setup.R in a text editor
  Find line ~18 and update with YOUR OneDrive path:
  
  onedrive_path <- "C:/Users/YourName/OneDrive/DIGIvloot - data - data"
  
  Save the file.

STEP 3: Run setup
  > source("00_setup.R")
  
  This creates the folder structure in OneDrive and installs packages.

STEP 4: Configure your bearer token
  > usethis::edit_r_environ()
  
  Add this line (replace with your actual token):
  POSEIDAT_TOKEN=your_bearer_token_here
  
  Save, close, and RESTART R

STEP 5: Load the functions
  > source("01_api_functions.R")
  > source("02_storage_functions.R")
  > source("03_deletion_functions.R")

STEP 6: Start fetching data!
  > vessels <- c("NLD123456", "NLD789012")
  > all_data <- get_all_vessel_data(vessels, "2024-01-01", "2024-12-31")
  > save_all_poseidat_data(all_data, c("2024-01-01", "2024-12-31"))

TYPICAL WORKFLOW

2. SAVE TO PARQUET

3. LOAD WHEN NEEDED
   trips <- load_poseidat_data("trips")
   catches <- load_poseidat_data("catches")

4. ANALYZE
   trip_summary <- trips |>
     left_join(catches |> group_by(trip_id) |> summarise(...))

5. UPDATE PERIODICALLY
   updated <- update_poseidat_data(vessels, "trips")

================================================================================
GDPR COMPLIANCE
================================================================================

If a vessel owner requests data deletion:

1. DRY RUN (preview):
   delete_vessel_data("NLD123456", "Owner request", "John Smith", dry_run = TRUE)

2. EXECUTE:
   report <- delete_vessel_data("NLD123456", "Owner request", "John Smith", dry_run = FALSE)

3. VERIFY:
   verify_vessel_deletion("NLD123456")

4. CERTIFICATE:
   generate_deletion_certificate(report$deletion_id)

All deletions are logged in: data/audit/deletions/
